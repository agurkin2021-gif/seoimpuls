# SEOImpuls — post-page white-hat reconstruction

Status: planning; baseline **not** approved for public republishing.

## Migration policy

1. Preserve exact production baseline and file provenance (original ZIP outside repository).
2. Work in `white-seo-rebuild`, never automatically deploy to production.
3. Inventory current live URL → original content file → Title → H1 → canonical → inbound/internal links → intended revised URL.
4. Map search intent and SERP results page by page (organic top 10, query, geo, language, date, competitor URL and content gaps).
5. Agree future service portfolio on real capabilities: technical SEO, site architecture, keyword research, on-page optimization, content strategy, indexation diagnostics, international SEO and consultation.
6. Remove all mass link sales, artificial DR manipulation, XRumer/GSA/XEvil-based services, tiered link schemes, satellites/PBN as ranking manipulation, and promotional hints of these.
7. Do not repurpose legacy URL paths misleadingly. If not a true topical successor, retire it with 404/410; update links and sitemap, preserve historical evidence.
8. Make EN homepage and service taxonomy first; EN support pages; audit internal overlap; then RU and ES localization, with per-language SERP intent.
9. Technical gate: Hugo build, internal link crawler, accessibility and responsiveness, canonical, hreflang reciprocal, sitemap, meta and structured data validity, alt labels, robots, redirects/410 plan.
10. Only after complete QA approve a deployment package for external VPS; GitHub Pages is not a deployment target.

## Rollout

- Phase 0: Secure import, capture baseline, SEO URL inventory, noindex policy for private preview, define non-grey service portfolio.
- Phase 1: EN homepage and sitewide navigation / footer.
- Phase 2: EN service overview and individual eligible service pages.
- Phase 3: About, FAQ, news, soft/tool pages; remove retired services and revise legal pages honestly.
- Phase 4: RU localized content and URL map.
- Phase 5: ES localized content and URL map.
- Phase 6: End-to-end cross-language SEO, Core Web Vitals and deployment checks.

## Critical restrictions

- **Do not deploy** anything during editing without separate user approval.
- **Do not mask** manipulative services with seemingly legitimate terminology.
- Do not assume a generic content rewrite will reverse Google filtering or spam-policy effects.
