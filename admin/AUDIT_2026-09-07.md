# Аудит админки: 7 сентября 2026

В сценариях наполнения были воспроизводимые ошибки. Исправления внесены, добавлены регрессионные тесты.

## Найдено и исправлено

| Приоритет | Ошибка | Исправление |
| --- | --- | --- |
| Высокий | Переход во время сохранения менял страницу назначения | Фиксация пути, блокировка повторного сохранения и перехода до завершения |
| Высокий | Старая вкладка перезаписывала свежую версию | Проверка версии файла под блокировкой; конфликт возвращает 409 |
| Высокий | Предпросмотр отсутствующего ресурса запускал сборку | Удалён запуск Hugo из GET `/site/` |
| Высокий | Быстрые сохранения перезаписывали бэкап в пределах секунды | Уникальная папка для каждого бэкапа |
| Высокий | Запись могла оставить неполный файл при ошибке | Временный файл и атомарная замена; проверен отказ замены |

## Границы

Проверка версии применяется к обычному сохранению страницы из обновлённого интерфейса. Старые API-клиенты без `expectedRevision` остаются совместимыми, но не получают эту защиту. Операции над несколькими файлами не являются общей транзакцией.

Бэкапы и загруженные файлы намеренно остаются на диске: кнопка сброса очищает временное состояние редактора, а не историю или медиа. Автоматическое удаление этих данных не добавлялось.

Реальная публикация и управление удалённым сервером не тестировались. Аудит подтверждает перечисленные сценарии, но не означает отсутствия любых будущих ошибок.

## Дополнение: переходы после запуска с ярлыка

Позднее пользователь показал ошибку клика по меню на порту 8788. Она воспроизведена: проверка внутренних ссылок учитывала только 8787/1314, рамка открывала адрес без `/site/`, получала `Not found`, а редактор накладывал прежние блоки на ошибку. Предыдущая проверка не охватила реальные клики на резервном порту.

Исправлено распознавание текущего адреса админки, добавлена проверка адреса документа перед наложением блоков и восстановление ошибочного перехода. Неизвестные внутренние ссылки больше не уводят рамку на страницу ошибки. Ярлык и автоматический выбор порта сохранены.

На рабочем 8788 проверены клики RU/EN/ES с контролем итогового адреса и H1: ошибок JavaScript и запросов записи нет, контент/public не изменились. Результаты: `test-artifacts/navigation-live-audit.json`. В регрессионный набор добавлены четыре проверки навигации и ошибок предпросмотра.
